# WAYOUT — Phase 1 source register

**Access/review date for all entries: 17 September 2026.** Year below refers to the dataset/event, not the search engine crawl date. "Not stated" means no explicit licence was verified; publicly readable is not equivalent to openly licensed. All variables are **proposed for use**, not already loaded. **Preprocessing performed: none for every entry.** Processing instructions below are prospective.

Status: **P** = publisher page or catalogue reviewed; **L** = specific file/download control identified, binary contents not validated; **R** = reference publication, not a verified analysis-ready GIS layer; **B** = access or essential metadata unresolved. These statuses are independent of scientific usefulness.

## Metadata contract for the future MySQL `data_sources` table

Recommended fields: `source_id`, `dataset_name`, `organisation`, `source_page_url`, `download_url`, `accessed_at`, `downloaded_at`, `region_id`, `coverage_description`, `observation_start`, `observation_end`, `publication_year`, `version`, `variables_used`, `format`, `crs`, `resolution`, `licence_name`, `licence_url`, `official_status`, `verification_status`, `raw_path`, `sha256`, `preprocessing_log`, `limitations`.

Keep a child resource record for each separate file, scenario and revision. Do not assign a single "2026" year to every source because it was accessed in 2026. Record NULL for unverified metadata. This is a Phase 1 metadata proposal, not an implemented MySQL schema.
